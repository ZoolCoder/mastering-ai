== What to look for

Run it. The output looks like this:

[source,text]
----
epoch    0  loss 0.2500
epoch  200  loss 0.0739
...
epoch 1800  loss 0.0266
learned: cloudy 2.40  rain 11.89  bias -5.94
cloudy, 80% rain  ->  1.00
clear,  10% rain  ->  0.01
----

* The loss falls fast at first, then slowly: the valley gets flatter.
* The rain weight ends about five times larger than the cloudy weight. The neuron
  discovered that rain chance matters more. Nobody told it.

== Experiments

. Set `LEARNING_RATE` to `0.01`, then to `50`. How fast does the loss fall?
. Change the rule in `label()` so the umbrella depends only on clouds. What do
  the learned weights look like now?
. Set `EPOCHS` to `50`. Are the predictions still confident?

[%collapsible]
.What you should see
====
. At `0.01` training crawls: the loss is still near 0.2 after 2,000 epochs
  and the predictions are vague. At `50` it learns faster. One sigmoid neuron
  is a gentle valley; in deep networks a rate that large usually overshoots
  and the loss blows up.
. The cloudy weight grows large (about 7) and the rain weight falls to around
  zero or below. The neuron found that rain no longer matters.
. No. The weights stay small, so a clear day with 10% rain still gets 0.35:
  the neuron has the right direction but has not walked far enough downhill.
====
