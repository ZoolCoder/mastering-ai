== After this part you can

* Explain the difference between AI, machine learning and deep learning.
* Say what a model, a parameter and a dataset are.
* Explain how a network improves by reducing its error, step by step.
* Read the phrase "a 70-billion-parameter model" and know what it means.

Time: about 5 hours, including the lab.
