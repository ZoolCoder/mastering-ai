A model can only use what is in its context window. Context engineering is choosing the smallest set of tokens that gets the job done.
--

== After this part you can

* Build a RAG pipeline and say which stage causes a bad answer.
* Decide what goes into context, what is retrieved on demand, and what is left out.
* Keep a long-running conversation useful with compaction and memory.
