== Lessons

. Pick a problem worth automating
. Design: workflow or agent, tools, context and state
. Build the agent and its tools
. Build the harness: instructions, checks and a loop
. Evals and a safety review
. Ship it and write it up

== After this part you can

* Take an AI idea from blank page to a working, tested, documented project.
* Defend every design choice with what you learned in parts 1 to 10.
