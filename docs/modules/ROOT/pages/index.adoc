== What you will be able to do

By the end of the full course you can:

* Explain how a neural network learns and how a large language model (LLM)
  writes text, without hand-waving.
* Write prompts that work the first time, and test them like code.
* Build an app on a model API: tools, structured output, streaming, caching.
* Give a model the right context with retrieval (RAG) and memory.
* Build an agent loop from scratch, then with an SDK and MCP.
* Work with coding agents such as Claude Code and Codex, the way strong teams do.
* Engineer the harness: the instructions, tools, checks and loops that turn a
  capable model into a reliable one.
* Ship it safely: evals, guardrails, prompt-injection defence and cost control.

== Why another course?

Good free material exists, but each covers one slice: model internals, or
building GenAI apps, or harness engineering. This course connects them into one
path, so each idea has the foundation it needs and leads to the next. Where an
existing course explains something best, we link to it instead of repeating it.
See xref:resources.adoc[] for the courses we build on.

TIP: New to all of this? Read xref:how-to-learn.adoc[] first. It takes three
minutes and tells you how to get the most out of each lesson.
