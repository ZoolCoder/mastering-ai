# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: this is a course for beginners. Be welcoming to people who are new,
patient with questions that seem basic, and respectful in disagreement.
Harassment, insults and personal attacks are not accepted, in issues, pull
requests or anywhere else the project lives.

## Reporting

To report a problem privately, use
[a private security advisory](../../security/advisories/new) on this repository,
or contact the maintainer, [@zoolcoder](https://github.com/zoolcoder), on
GitHub. Reports are kept confidential.
